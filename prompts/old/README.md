# Archived prompt versions

YAML files moved here are **not** loaded by the pipeline. Only versions referenced in [`configs/agents.json`](../configs/agents.json) under `packages/openai/configs/` are operational.

These copies are kept for history and diff reference. Do not point `agents.json` at files in this tree.

See [`docs/PROMPT_LANGUAGE.md`](../../docs/PROMPT_LANGUAGE.md) for wording standards.
